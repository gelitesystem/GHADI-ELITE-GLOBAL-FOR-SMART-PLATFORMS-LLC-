 # 🚀 Ghadi Elite - G-Smart Platform (المنصة الذكية المتكاملة)

منصة ويب ثابتة (Static Web Platform) مصممة لتقديم واجهة مستخدم سريعة وفعالة مع التركيز على الأداء والأمان وسهولة النشر عبر خدمات Google Cloud.

---

## 🌟 الهيكل العام والميزات الرئيسية

### محتويات المجلد: `g-elite-g-smart-platform/`

هذا المشروع يمثل واجهة أمامية نقية، حيث يتم بناء وتخزين كل شيء داخل المجلد الرئيسي:

*   `index.html`: الصفحة الرئيسية للمنصة.
*   `activities.html`: صفحة الأنشطة.
*   `legal.html`: صفحة الشروط والأحكام والخصوصية.
*   `css/`: ملفات تنسيق الأنماط (Stylesheets).
*   `js/`: ملفات جافاسكربت للتفاعل والمنطق (Scripts).
*   `image/`: الأصول الرسومية والصور.

### الميزات التقنية (كما تم توثيقها في ملفات الكود)

*   **تصميم متجاوب:** بنية أساسية سريعة التحميل ومتوافقة مع جميع الأجهزة.
*   **دمج الذكاء الاصطناعي:** يعتمد على مفاتيح API خارجية (`OPENAI_API_KEY`, `GEMINI_API_KEY`) لتشغيل الخدمات الذكية.
*   **هيكل أمان مُعزز:** فصل كامل لمتغيرات البيئة والمفاتيح الحساسة في مجلدات خارجية (`~/.env` و `~/secrets`).

---

## ⚙️ بيئة العمل والإعداد التقني (Deployment & Setup)

يتم نشر هذا المشروع كـ **موقع ثابت (Static Site)** عبر خدمة Google Cloud Storage (GCP) باستخدام الأداة **Rclone**.

### 1\. الإعدادات الخارجية المطلوبة

للتشغيل والرفع بنجاح، يجب توفر ملفات الإعداد والمفاتيح في المسارات المطلقة التالية:

| المكون | المسار المتوقع (مثال) | الأهمية |
| :--- | :--- | :--- |
| **ملف متغيرات البيئة** | `~/.env` | يحتوي على مفاتيح API ومسارات المفاتيح. |
| **مجلد المفاتيح** | `~/secrets/` | يحتوي على ملفات JSON الخاصة بحسابات الخدمة (Service Accounts) ومفاتيح Firebase Admin SDK. |
| **أداة النشر** | Rclone | يجب أن تكون مُثبتة ومُعدّة بثلاثة ريموتات: `firebase:`, `gcp-main:`, `gcp-gemini:`. |

> ⚠️ **تنبيه أمان:** **يمنع منعاً باتاً** تضمين أي من ملفات `.env` أو `secrets/` داخل هذا المستودع.

### 2\. وجهة النشر (Rclone Configuration)

النشر يستهدف الريموت المُسمى **`gcp-gemini:`**، والمُعد مسبقًا لربط دلو التخزين التالي:

| الإعداد | القيمة |
| :--- | :--- |
| **اسم الريموت** | `gcp-gemini` |
| **نوع التخزين** | Google Cloud Storage |
| **دلو التخزين (Bucket)** | `g-elite-g-smart-platform-gemini-bluket` |
| **مسار المفتاح (داخل Rclone)** | `/data/data/.../secrets/g-elite-g-smart-platform-664c5dffe7e6.json` |
